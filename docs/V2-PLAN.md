# ILQue V2 실행 계획

기준: [Notion — 2026-09-11 고도화 방향](https://app.notion.com/p/3597cdef782d81a99db4d6cc7d548544). 페이지 전체, 하위 검색, 저장소, 연결된 브라우저에서 승인된 Figma 링크를 찾지 못했다. 따라서 사용자 지시에 따라 Learning Dashboard × RPG Quest × Friendly Productivity 방향으로 구현한다.

1. 기존 Google OAuth / Calendar / Gemini / Notion / Supabase 연결을 재사용한다. 토큰 세션 노출, 로그인 XP 초기화, 미검증 AI 결과, 매 조회 AI 재호출을 수정한다.
2. 목표·마감·가용 시간·고정 일정·실측 시간·완료율·이월·수동 변경을 반영하는 순수 결정론적 스케줄러를 만든다. AI는 명시적 요청에만 작업을 분해한다.
3. 퀘스트·목표·자료·미션·기록·설정을 영속 저장하고 원자적 버전 비교로 동시 수정 및 중복 XP를 방지한다. 기존 데이터는 보존하고 가져온다.
4. 오늘을 중심으로 8개 한국어 화면을 구현한다. 청록·크림 기반, 차분한 RPG 동기 부여, 반응형 탐색과 명확한 다음 행동을 제공한다.
5. 엔진/경계/API/저장 테스트, 실제 브라우저 기능·반응형 QA, 오류 수정, production build, README를 완료한다.

## 확인된 기존 문제

- 로그인 프로필 upsert에 xp=0, level=1, streak=0이 포함됨.
- session callback이 Calendar access token을 클라이언트 세션에 넣음.
- 오늘 화면 조회마다 AI를 호출하고 생성 결과를 저장하지 않음.
- 완료 API가 클라이언트가 보낸 XP를 신뢰하고 동일 퀘스트 중복 완료를 방지하지 않음.
- 날짜 계산이 서버 로컬/UTC에 혼재함.
- Supabase SQL은 text subject를 사용하는 서버 서비스 계정 모델. UUID로 전환해야 할 근거는 아직 없음.

## 검증 경계

실제 외부 서비스 접근 결과와 테스트 데이터 결과를 구분한다. 실패한 연동을 빈 데이터나 저장 성공으로 표시하지 않는다. 비밀은 로그·클라이언트·문서에 포함하지 않는다.
